# Annecy 2026 capture page — 2 June 2026

`/annecy` — `annecy.html` at project root.

Single-file HTML contact-capture card for Annecy / Mifa 2026.
Served at `https://www.curiousdreamers.com/annecy`.

## What it does

- Full-screen gate with CURIOUS DREAMERS wordmark + "Waking The Imagination" tagline.
- On tap: gate fades, card content reveals with staggered fade, sting video plays.
- Showcase block: Teatrino + WndrKlub (brand image slots in `/assets/`).
- Name + email form. POSTs JSON to `CONFIG.captureEndpoint`.
- Success state replaces the form on 2xx response.

## Config

All adjustable values are in the `CONFIG` object at the top of the script:

| Key | Value |
|---|---|
| `source` | `cd-card` |
| `source_detail` / `event` | `annecy-2026` |
| `captureEndpoint` | `https://giles-engine.gileslamb.workers.dev/capture` |
| `accent` | `#d4a843` (Teatrino gold) |
| `videoSrc` | Cloudflare Stream HLS — sting video |

## Fonts

Pulled directly from `curiousdreamers.com`:
- Wordmarks: Syne 800
- Body / form: Bricolage Grotesque
- Labels / mono: DM Mono

## Backend

The `/capture` endpoint on `giles-engine` is **not yet wired** to accept `source: "cd-card"`.
Until it is, the POST will fail with a CORS or 4xx response — the form shows an error,
button re-enables. Expected behaviour for now.
